\section{Introduction and Experimental Scope}
\label{sec:supp_introduction}

This supplementary document provides a comprehensive repository of empirical evaluation curves, feature allocation topologies, statistical seed stability breakdowns, and multi-metric architectural ablation logs that substantiate our main manuscript. While the primary paper concentrates on key comparative benchmarks, architectural innovations, and high-level XAI interpretations, this document presents the complete, untruncated experimental evidence required to ensure full reproducibility and scientific transparency of the results.

Specifically, this supplementary material encompasses eleven structured sections:
\begin{enumerate}
    \item \textbf{Section~\ref{sec:supp_introduction} -- Introduction and Experimental Scope}: Details the overarching motivation, structural outline, and rigorous experimental protocols governing all evaluations.
    \item \textbf{Section~\ref{sec:supp_eda_visualizations} -- Exploratory Data Analysis and Feature Visualizations}: Examines target class distributions, inter-feature Pearson correlation heatmaps, and marginal feature value distributions across all four evaluated benchmark datasets (Apose-IoT-23, BoT-IoT, CIC-IoMT-2024, and CIC-IoT-2025).
    \item \textbf{Section~\ref{sec:supp_apose_results} -- Apose-IoT-23 Dataset Results}: Compiles full ROC, PR, and probability calibration curves for binary and multiclass tasks on Apose-IoT-23.
    \item \textbf{Section~\ref{sec:supp_bot_results} -- BoT-IoT Dataset Results}: Presents performance curves and calibration diagnostics across 1.5 million test flows on BoT-IoT.
    \item \textbf{Section~\ref{sec:supp_iomt_results} -- CIC-IoMT-2024 Dataset Results}: Details binary and 19-class IoMT healthcare telemetry performance profiles.
    \item \textbf{Section~\ref{sec:supp_iot25_results} -- CIC-IoT-2025 Dataset Results}: Demonstrates multi-protocol smart home intrusion detection across 8 threat classes.
    \item \textbf{Section~\ref{sec:supp_feature_ablation} -- User-Selected Feature Subsets for Feature Ablation}: Reports the complete XAI-selected feature allocation lists and training/validation loss trajectories for compact feature models.
    \item \textbf{Section~\ref{sec:supp_arch_ablation} -- Detailed Architectural Ablation Breakdown}: Reports multi-metric accuracy, classification error rates, macro precision, recall, F1-scores, inference duration, and per-sample latencies across architectural variants.
    \item \textbf{Section~\ref{sec:supp_per_seed_eval} -- Per-Seed Evaluation Breakdown and Cross-Seed Metric Correlation Analysis}: Examines statistical metrics across five independent random seeds ($S=\{13, 23, 33, 43, 53\}$) and inter-metric Pearson correlation dynamics.
    \item \textbf{Section~\ref{sec:supp_detailed_class_perf} -- Comprehensive Per-Seed Class-by-Class Evaluation Metrics Breakdown}: Provides full class-by-class precision, recall, and F1-score breakdowns for every seed run across all eight dataset tasks.
    \item \textbf{Section~\ref{sec:supp_cross_dataset} -- Summary of Cross-Dataset Zero-Shot Transferability and Operational Synthesis}: Discusses domain adaptation mechanics, out-of-distribution transfer resilience, and computational inference throughput.
\end{enumerate}

\subsection{Experimental Rigor and Partitioning Hygiene}
All benchmark experiments reported in the main manuscript and this supplementary document adhere to a strict leakage-free data hygiene protocol:
\begin{itemize}
    \item \textbf{Partitioning Ratio}: Datasets are split into 70\% training, 15\% validation, and 15\% testing subsets. Splits are performed prior to any normalisation or feature extraction to prevent data leakage.
    \item \textbf{No Downsampling}: To reflect real-world operational network traffic conditions, no artificial downsampling or synthetic oversampling (e.g., SMOTE) was applied to the evaluation sets, preserving genuine class imbalance ratios (e.g., benign flow rates as low as 0.013\% in BoT-IoT).
    \item \textbf{Multi-Seed Verification}: All models were trained and evaluated across five independent random seeds ($S = \{13, 23, 33, 43, 53\}$) to calculate mean and standard deviation across five independent seed runs and evaluate robustness to random initialization.
\end{itemize}

For each dataset, three key visualisation modalities were examined: (i) target class distributions for binary and multiclass configurations, (ii) inter-feature Pearson correlation heatmaps, and (iii) marginal feature value distributions (histograms). Because inter-feature correlations and marginal feature value distributions depend exclusively on dataset feature measurements and are invariant to target class framing, single representative correlation heatmap and marginal feature distribution figures are presented for each dataset.

\section{Detailed Architectural Ablation Breakdown (Metrics, Loss Rates, and Latencies)}
\label{sec:supp_arch_ablation}

To provide comprehensive empirical backing for the ablation analysis reported in Section~6.5.1 of the main manuscript, this section provides detailed performance breakdowns and computational training efficiency profiles across all four architectural variants:
\begin{enumerate}
    \item \textbf{CNN Branch Only:} Isolates spatial feature extraction via 1D convolutional filters.
    \item \textbf{BiLSTM Branch Only:} Isolates recurrent feature-channel encoding via bidirectional LSTM units.
    \item \textbf{Fusion (without Attention Gating):} Concatenates spatial (CNN) and recurrent (BiLSTM) feature vectors without dynamic scale normalization.
    \item \textbf{Full Proposed Framework:} Integrates parallel CNN spatial filtering, BiLSTM recurrent feature-channel encoding, and dynamic softmax attention-based feature gating.
\end{enumerate}

Table~\ref{tab:supp_arch_ablation_detailed} reports the comprehensive classification accuracy, error/loss rates ($100\% - \text{Accuracy}$), macro precision, macro recall, macro F1-score, total inference time (seconds), and amortised per-sample latency (ms/sample). Table~\ref{tab:supp_arch_efficiency_detailed} lists the corresponding training efficiency metrics, including the completed training epochs, total training time, estimated training batch latency, hardware device, and runtime-derived training energy proxy.

\subsection{Analysis of Classification Metrics and Inference Latencies (Table~\ref{tab:supp_arch_ablation_detailed})}

As presented in Table~\ref{tab:supp_arch_ablation_detailed}, the empirical results demonstrate the individual strengths and structural interactions among architectural components:
\begin{itemize}
    \item \textbf{Single-Branch Baselines:} The standalone \textit{CNN Branch Only} and \textit{BiLSTM Branch Only} models deliver strong baseline classification performance. The CNN branch achieves low error rates ($0.556\%$ on Apose-IoT-23 binary, $0.001\%$ on BoT-IoT binary, $0.162\%$ on CIC-IoMT-2024 binary) with rapid amortised per-sample batch inference latencies ranging from $0.0082$~ms to $0.0150$~ms/sample. Similarly, the BiLSTM branch provides recurrent feature-channel encoding for singleton input sequences ($0.857\%$ error rate on Apose-IoT-23 multiclass, $0.782\%$ on CIC-IoMT-2024 multiclass) with amortised per-sample batch inference latencies of $0.0087$~ms to $0.0142$~ms/sample.
    \item \textbf{Impact of Unweighted Concatenation:} Omitting the attention-gating layer (\textit{Fusion w/o Attention Gating}) causes severe classification degradation and massive error rate spikes across multiple tasks (error rates reaching $26.738\%$ on Apose binary, $99.511\%$ on BoT-IoT multiclass, $97.937\%$ on CIC-IoMT binary, and $58.412\%$ on CIC-IoT-2025 binary). This failure occurs because the raw 1D-CNN feature maps and BiLSTM hidden state vectors operate at uncalibrated activation scales, creating ill-conditioned loss gradients that distort decision boundaries.
    \item \textbf{Performance Recovery via Attention Gating:} The \textit{Full Proposed Framework} incorporates dynamic softmax attention gating ($\alpha = \text{softmax}(e)$), which rescales spatial and recurrent feature vectors dynamically per sample. This restores the gradient stability and eliminates the catastrophic representation collapse observed in unweighted fusion. Although standalone single branches obtain slightly higher metrics on specific datasets (e.g., the BiLSTM branch on CIC-IoMT-2024 multiclass with $99.218\%$ accuracy and $81.650\%$ F1 vs. $98.049\%$ accuracy and $75.981\%$ F1 for the full framework), attention gating is critical for stabilising dual-branch fusion, providing consistent, robust performance across heterogeneous IoT traffic domains while maintaining ultra-low amortised per-sample batch inference latencies ($0.0088$--$0.0134$~ms/sample).
\end{itemize}

\subsection{Analysis of Training Efficiency and Resource Consumption (Table~\ref{tab:supp_arch_efficiency_detailed})}

Table~\ref{tab:supp_arch_efficiency_detailed} summarizes the computational training footprint across architectural variants under fixed hyperparameter settings ($\text{Seed} = 42$, $\text{Batch Size} = 256$, CUDA GPU):
\begin{itemize}
    \item \textbf{Training Execution Latency per Batch:} The standalone \textit{CNN Branch Only} model exhibits the shortest training batch processing latency ($5.513$--$5.922$~ms/batch), reflecting the parallel efficiency of 1D convolutions. The \textit{BiLSTM Branch Only} model requires slightly higher computation ($5.862$--$6.373$~ms/batch) due to recurrent state propagation.
    \item \textbf{Fusion Overhead and Convergence:} Unweighted fusion (\textit{Fusion w/o Attention Gating}) increases training batch latency ($6.624$--$7.466$~ms/batch) and exhibits premature early-stopping (e.g., terminating at Epoch~9 on Apose multiclass and Epoch~15 on BoT-IoT binary) due to loss trajectory instability.
    \item \textbf{Full Framework Resource Efficiency:} The \textit{Full Proposed Framework} combines parallel convolutional spatial filtering and BiLSTM recurrent feature-channel encoding with attention gating at a modest training batch latency increase ($7.006$--$9.102$~ms/batch). It achieves smooth loss convergence across 19--20 full epochs, requiring total training times ranging from $10.52$~s on compact datasets (Apose-IoT-23) to $3,866.91$~s ($\approx 1.07$~hours) on the full-scale BoT-IoT dataset (7.0 million training flows), with GPU runtime-derived energy proxies ($1,261.91$~J for Apose binary, $22,026.79$~J for CIC-IoT-2025 binary, and $464,029.00$~J for BoT-IoT binary; calculated as execution time multiplied by an assumed 120 W GPU load rating, as no direct power-meter measurement was performed).
\end{itemize}

\subsection{Analysis of Architectural Ablation Confusion Matrices (Table~\ref{tab:supp_arch_confusion_matrices})}

To provide a granular, class-by-class evaluation of decision boundary behaviour and misclassification patterns across architectural variants, Table~\ref{tab:supp_arch_confusion_matrices} compiles the exact confusion matrix distributions extracted from the architectural ablation experiments across all eight dataset tasks. For each target class label, the table reports sample support, correctly classified instances (true positives, TP), misclassified instances (false negatives, FN), and the primary target class receiving the misclassified flows.

The class-level confusion distributions reveal three fundamental architectural findings regarding feature representation, scale alignment, and gating stabilisation.

\subsubsection{Single-Branch Feature Discrimination and Minority-Class Vulnerabilities}
The standalone \textit{CNN Branch Only} and \textit{BiLSTM Branch Only} models establish strong baseline discrimination across majority traffic classes:
\begin{itemize}
    \item \textbf{Binary Tasks:} The spatial 1D-CNN branch correctly classifies 1,139/1,155 Attack flows in Apose-IoT-23 binary, 1,499,802/1,499,805 Attack flows in BoT-IoT binary, 1,267,000/1,268,491 Attack flows in CIC-IoMT-2024 binary, and 37,109/37,851 Attack flows in CIC-IoT-2025 binary. The recurrent BiLSTM branch achieves comparable majority-class recall (1,138/1,155 in Apose binary, 1,499,791/1,499,805 in BoT-IoT binary, and 37,077/37,851 in CIC-IoT-2025 binary).
    \item \textbf{Multiclass Minority Limitations:} However, single-branch architectures exhibit localized vulnerabilities on highly imbalanced minority attack categories. For example, in Apose-IoT-23 multiclass classification, the standalone CNN branch fails completely on the \textit{Okiru} botnet malware class (0/22 correct, misclassifying all 22 flows into \textit{PortScan}) because localised spatial convolutions cannot capture non-linear feature relationships. Conversely, the BiLSTM branch performs a singleton-sequence bidirectional feature transformation, successfully capturing these non-linear feature relationships (21/22 correct). In BoT-IoT multiclass, the CNN branch misses stealthy \textit{Keylogging} attacks (0/30 correct), whereas BiLSTM captures 2/30. This demonstrates that relying on a single feature modality leaves critical coverage gaps for specialised IoT threat vectors.
\end{itemize}

\subsubsection{Mechanisms of Categorical Collapse Under Unweighted Fusion}
Disabling the attention-gating mechanism (\textit{Fusion w/o Attention Gating}) and directly concatenating spatial feature maps $\mathbf{h}_{cnn} \in \mathbb{R}^{d_c}$ and recurrent hidden states $\mathbf{h}_{lstm} \in \mathbb{R}^{d_l}$ causes severe categorical collapse across multiple tasks:
\begin{itemize}
    \item \textbf{Binary Categorical Bias:} In Apose-IoT-23 binary classification, unweighted fusion misclassifies 1,154/1,155 Attack flows into the majority \textit{Benign} class (achieving only 1 True Positive). In CIC-IoMT-2024 binary, 1,268,474/1,268,491 Attack flows are misclassified into \textit{Benign} (achieving only 17 True Positives). In CIC-IoT-2025 binary, 37,842/37,851 Attack flows collapse into \textit{Benign} (9 True Positives).
    \item \textbf{Multiclass Collapse:} In BoT-IoT multiclass classification, unweighted fusion collapses entirely into predicting a single majority class (\textit{OS\_Fingerprint}), yielding 0 correct predictions across 1,012 HTTP, 30 Keylogging, 195 Normal, 651,425 TCP, and 810,094 UDP flows. In CIC-IoMT-2024 multiclass, unweighted fusion predicts \textit{TCP\_IP-DoS-ICMP} for all 1.29 million test flows, resulting in 0 correct predictions across 18 out of 19 classes. In CIC-IoT-2025 multiclass, the unweighted model predicts \textit{benign} for all 64,785 flows, completely missing 5 out of 8 threat categories.
    \item \textbf{Theoretical Rationale:} This phenomenon occurs because unnormalized spatial convolutions and recurrent hidden states operate at disparate activation magnitudes ($\|\mathbf{h}_{cnn}\|_2 \neq \|\mathbf{h}_{lstm}\|_2$). Unweighted concatenation distorts the logit activation scale $\mathbf{z} = \mathbf{W}[\mathbf{h}_{cnn} \,\|\, \mathbf{h}_{lstm}] + \mathbf{b}$, pushing backpropagation gradients into flat saturation regions of the Cross-Entropy loss surface and causing the final dense layer to overfit strictly to the baseline class prior probability.
\end{itemize}

\subsubsection{Restoration of Decision Boundaries in the Full Proposed Framework}
Incorporating the attention-based feature-gating layer in the \textit{Full Proposed Framework} completely eliminates categorical collapse and restores precise multiclass decision boundaries:
\begin{itemize}
    \item \textbf{Dynamic Feature Rescaling:} The gating module computes dynamic, instance-level softmax weight vectors $\alpha = \text{softmax}(\mathbf{W}_g [\mathbf{h}_{cnn} \,\|\, \mathbf{h}_{lstm}])$, dynamically rescaling spatial and recurrent sub-vectors prior to classification.
    \item \textbf{High-Recall multiclass Separation:} In Apose-IoT-23 multiclass, the full model restores balanced detection across all five categories (3,151/3,161 Benign, 1,024/1,028 CandC, 22/52 DDoS, 21/22 Okiru, and 39/53 PortScan). In BoT-IoT multiclass, it recovers 1,006/1,012 HTTP, 164/195 Normal, 28,251/29,917 Service\_Scan, 651,413/651,425 TCP, and 810,076/810,094 UDP flows.
    \item \textbf{Healthcare and Smart Home Protection:} In CIC-IoMT-2024 multiclass, the full model achieves robust detection across all 19 specialized IoMT attack types (282,382/282,978 TCP\_IP-DDoS-ICMP, 145,485/146,151 TCP\_IP-DDoS-SYN, 147,683/148,059 TCP\_IP-DDoS-TCP, 298,574/299,704 TCP\_IP-DDoS-UDP, 102,683/105, 675 TCP\_IP-DoS-UDP, 32,157/32,243 MQTT-DDoS-Connect\_Flood). In CIC-IoT-2025 multiclass, it accurately detects all eight smart home threat categories (26,794 benign, 628 bruteforce, 7,480 ddos, 8,119 dos, 3,293 malware, 3,399 mitm, 12,399 recon, and 1,141 web).
\end{itemize}

\subsection{Dataset-by-Dataset Per-Seed Correlation and Variability Analysis}
An in-depth analysis of Table~\ref{tab:supp_per_seed_metrics} across all individual dataset tasks reveals important empirical insights into model initialization stability, metric convergence, and computational scaling:

\begin{enumerate}
    \item \textbf{Apose-IoT-23 Benchmark Analysis:}
    \begin{itemize}
        \item \textit{Binary Classification:} Across the five independent seeds, binary accuracy remains exceptionally tight, ranging from $98.888\%$ (Seed~23) to $99.513\%$ (Seed~53), with a mean of $99.333 \pm 0.234\%$. Macro F1-scores closely track accuracy ($98.574\%$ to $99.379\%$), indicating relatively balanced discrimination between benign and attack classes. Macro ROC-AUC values exhibit minimal variance ($99.689\%$ to $99.818\%$), confirming stable class separability across random weight initialisations. GPU batch inference latencies remain highly consistent at $3.976$--$5.608$~ms per batch.
        \item \textit{Multiclass Classification:} In the 5-class threat scenario, accuracy ranges from $98.424\%$ (Seed~23) to $99.235\%$ (Seed~13). Macro F1-score shows moderate variance ($80.271\%$ on Seed~43 to $92.733\%$ on Seed~13), which directly correlates with localised minority class decision boundaries (e.g., \textit{Okiru} payload transfers and rare \textit{PortScan} samples). Despite minority F1 fluctuations, macro ROC-AUC remains consistently high ($98.698\%$ to $99.531\%$), confirming that decision confidence scores retain strong class separability across all seeds.
    \end{itemize}

    \item \textbf{BoT-IoT Benchmark Analysis:}
    \begin{itemize}
        \item \textit{Binary Classification:} On the massive BoT-IoT dataset (evaluating 1.50 million test flows), accuracy achieves near-perfect stability across all five seeds ($99.996\%$ to $99.998\%$, std $= 0.001\%$). Macro F1-score ranges from $93.222\%$ to $96.410\%$, reflecting the challenge of detecting rare benign background flows ($<0.1\%$ of total traffic). Macro ROC-AUC remains above $99.487\%$ across all runs ($99.896 \pm 0.204\%$). GPU evaluation total time is stabilised at $12.624$--$13.331$~s (~$4.309$--$4.550$~ms/batch).
        \item \textit{Multiclass Classification:} Across eight operational threat subclasses (\texttt{Normal}, \texttt{HTTP}, \texttt{TCP}, \texttt{UDP}, \texttt{OS\_Fingerprint}, \texttt{Service\_Scan}, \texttt{Keylogging}, and \texttt{Data\_Exfiltration}), multiclass accuracy exhibits near-zero deviation ($99.736\%$ to $99.753\%$, mean $99.744 \pm 0.006\%$). Macro F1-score ranges between $69.097\%$ and $70.967\%$, constrained primarily by severe support scarcity in rare subclasses (\textit{Keylogging} with 30 test samples and \textit{Data Exfiltration} with 2 test samples). However, high-volume classes (TCP and UDP attacks comprising $>99.9\%$ of data) achieve near-100\% recall across all seeds, maintaining a macro ROC-AUC of $99.189 \pm 0.903\%$.
    \end{itemize}

    \item \textbf{CIC-IoMT-2024 Benchmark Analysis:}
    \begin{itemize}
        \item \textit{Binary Classification:} For medical IoT telemetry, binary classification demonstrates exceptional reproducibility across all seeds ($99.825\%$ to $99.834\%$, std $= 0.003\%$). Macro F1-scores remain tightly bounded ($97.873\%$ to $97.965\%$), and macro ROC-AUC reaches near-perfect levels ($99.983\%$ to $99.987\%$). GPU evaluation completes in $11.337$--$11.649$~s (~$4.481$--$4.604$~ms/batch).
        \item \textit{Multiclass Classification:} Evaluating 19 specialized healthcare attack types, multiclass accuracy is highly stable ($99.175\%$ to $99.227\%$, mean $99.212 \pm 0.022\%$). Macro F1-scores range from $79.469\%$ to $82.291\%$, reflecting minor classification overlap in low-volume reconnaissance classes (\textit{Recon-OS\_Scan} and \textit{Recon-VulScan}). Dynamic feature gating maintains strong overall discrimination, yielding a macro ROC-AUC of $99.952 \pm 0.002\%$ across all five seeds.
    \end{itemize}

    \item \textbf{CIC-IoT-2025 Benchmark Analysis:}
    \begin{itemize}
        \item \textit{Binary Classification:} For high-dimensional smart home network traffic, binary classification exhibits remarkable stability across seeds ($98.714\%$ to $98.740\%$, std $= 0.009\%$). Macro Precision ($98.531\%$ to $98.569\%$), Macro Recall ($98.854\%$ to $98.868\%$), and Macro F1-score ($98.681\%$ to $98.708\%$) demonstrate near-zero initialisation sensitivity. Macro ROC-AUC is $99.842 \pm 0.007\%$, with GPU inference completing in under $0.83$~s (~$4.787$--$6.492$~ms/batch).
        \item \textit{Multiclass Classification:} Across eight smart home threat categories, multiclass accuracy ranges from $97.563\%$ to $97.666\%$ ($97.613 \pm 0.042\%$), while macro F1-score spans $96.069\%$ to $96.450\%$ ($96.292 \pm 0.140\%$). Macro ROC-AUC exceeds $99.88\%$ across all seeds, demonstrating high ranking discrimination across complex web attacks, bruteforce, DoS, DDoS, malware, MITM, and reconnaissance traffic. Probability calibration is separately verified through calibration curves (Figures~\ref{fig:apose_bin_cal}, \ref{fig:apose_multi_cal}, \ref{fig:bot_bin_cal}, \ref{fig:bot_multi_cal}, \ref{fig:iomt_bin_cal}, and \ref{fig:iot25_multi_cal}).
    \end{itemize}
\end{enumerate}

\section{Summary of Cross-Dataset Zero-Shot Transferability and Operational Synthesis}
\label{sec:supp_cross_dataset}

To evaluate the operational resilience and domain adaptation capabilities of the proposed hybrid framework, a cross-dataset evaluation was conducted across unseen IoT topologies and protocol stacks. In industrial and smart-home IoT deployments, intrusion detection models frequently encounter out-of-distribution network traffic generated by novel hardware devices and evolving attack payloads.

\subsection{Mechanisms Driving Domain Transfer Resilience}
As documented in Section~6.6 and Table~12 of the main manuscript, the proposed framework evaluates binary zero-shot cross-dataset transfer performance across heterogeneous IoT datasets. This cross-domain transfer capability is driven by four key principles:
\begin{enumerate}\setlength{\itemsep}{1pt}\setlength{\parskip}{0pt}
    \item \textbf{Common Binary Label Mapping}: Cross-dataset transfer is evaluated under the common binary ontology $\{\text{Benign}, \text{Attack}\}$. Multiclass cross-dataset transfer is omitted because benchmark datasets lack a unified class taxonomy.
    \item \textbf{Unsupervised Target-Domain Normalization}: Applies Z-score standardization ($\mathbf{x} = (\mathbf{x}_{\text{raw}} - \mu_{\text{tgt}}) / \sigma_{\text{tgt}}$) where $\mu_{\text{tgt}}$ and $\sigma_{\text{tgt}}$ are fitted strictly on $D_{\text{train}}^{(\text{tgt})}$, mitigating scale disparities while guaranteeing zero leakage from $D_{\text{test}}^{(\text{tgt})}$.
    \item \textbf{Deterministic Dimensional Adaptation Operator}: Adapts target feature vectors $\mathbf{x} \in \mathbb{R}^{d_{\text{tgt}}}$ to the source input dimension $d_{\text{src}}$ via $\psi_{\text{src} \leftarrow \text{tgt}}(\mathbf{x}) = \left[ \mathbf{x} \,\|\, \mathbf{0} \right]$ (if $d_{\text{tgt}} < d_{\text{src}}$) or truncation (if $d_{\text{tgt}} > d_{\text{src}}$), preserving model architecture compatibility without modifying weight matrices.
    \item \textbf{Attention-Based Feature Gating}: Dynamic softmax attention gating adaptively reweights fused spatial and recurrent representations, emphasizing informative channels prior to logit projection.
\end{enumerate}
