\section{Introduction}

This supplementary document provides a complete set of experimental evaluation curves and performance analyses for the proposed hybrid CNN--BiLSTM--Attention framework. The main manuscript contains representative plots for readability, whereas this document compiles all receiver operating characteristic (ROC), precision-recall (PR), and probability calibration charts for the eight distinct runs (four datasets under both binary and multi-class settings).

The benchmark datasets analyzed in this study are:
\begin{enumerate}
    \item \textbf{Apose-IoT-23}: 18 features, 16,598 test flows.
    \item \textbf{BoT-IoT}: 29 features, 18,342,580 test flows.
    \item \textbf{CIC-IoMT-2024}: 46 features, 2,158,647 test flows.
    \item \textbf{CIC-IoT-2025}: 94 features, 171,418 test flows.
\end{enumerate}

For each dataset, we present:
\begin{itemize}
    \item \textbf{ROC and Precision-Recall (PR) Curves}: Evaluating classification quality under different decision thresholds and addressing class imbalance.
    \item \textbf{Calibration Curves}: Showing the probabilistic reliability of model predictions.
\end{itemize}

All figures in this document are loaded from the dedicated \texttt{figures/} subdirectory to maintain a clean repository organisation. Detailed quantitative metrics (accuracy, precision, recall, F1-scores, training latency, and energy proxies) are already presented in a tabular format within the main manuscript (Tables 3, 5, 6, 7, and 8 of the main manuscript), and training/validation accuracy histories are illustrated in the main manuscript's learning curves.

The binary classification results for Apose-IoT-23 demonstrate high predictive capability. Furthermore, the calibration curve (Figure~\ref{fig:apose_binary_perf}c) is closely aligned with the ideal diagonal reference line ($y=x$), yielding a very low Brier score. This confirms that the model's confidence scores correspond to true empirical probabilities, making it reliable for risk-based network policy enforcement.

\section{Summary of Cross-Dataset Generalization}

Cross-dataset testing was performed to evaluate the robustness of the model. The performance remained high when tested on unseen networks, demonstrating that feature harmonisation across different feature representations successfully enabled the model to retain a strong predictive capability.

The minimal performance drop (typically within 1.5--4\%) is attributed to:
\begin{itemize}
    \item \textbf{Label Unification}: Standardizes heterogeneous threat classifications into a single binary or multiclass representation.
    \item \textbf{Z-Score Normalization}: Standardizes disparate feature scaling and ranges across different networks.
    \item \textbf{Attention Mechanism}: Dynamically weights features based on their relative importance in the current flow sequence, allowing the model to adapt to different network environments.
\end{itemize}

Overall, these supplementary results confirm the reliability, robustness, and generalisability of the proposed framework in heterogeneous IoT environments.
